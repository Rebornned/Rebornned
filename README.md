## Projetos

- **[spotify-explorer](https://github.com/Rebornned/spotify-explorer)**: aplicação web para explorar um catálogo de 89.740 músicas. ETL a partir de um dataset bruto de 114 mil registros, banco MySQL normalizado e API em Flask com consultas paginadas no banco. Python, Flask, SQLAlchemy, MySQL, React.
- **[round-robin-scheduler](https://github.com/Rebornned/round-robin-scheduler)**: simulador em terminal de escalonamento Round Robin com Feedback, com filas de prioridade e de I/O, estatísticas de turnaround e espera e testes automatizados. C.
- **[resonance](https://github.com/Rebornned/resonance)**: catálogo musical desktop com playlists persistentes em arquivos binários. C, GTK3.
- **[world-of-dragons](https://github.com/Rebornned/world-of-dragons)**: jogo de luta em turnos para desktop, com interface gráfica, áudio e save de progresso em arquivos binários. C, GTK3, SDL2.
